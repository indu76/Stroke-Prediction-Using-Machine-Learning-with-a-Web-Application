About This Model

This demo web app uses a machine learning model trained offline to estimate stroke risk from a few patient features. It is for educational purposes only and not a clinical tool.

  • Model and preprocessing objects are loaded from preprocessing_objects.pkl.
  • Make sure the model file (e.g., best_model_xgboost.pkl) is placed next to app.py.
